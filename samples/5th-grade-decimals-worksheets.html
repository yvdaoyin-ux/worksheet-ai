Answer Key

  1. \(4.25 + 2.376 = 6.626\).
    Step: Align decimals: \(4.250 + 2.376 = 6.626\).
  2. \(9.5 - 3.485 = 6.015\).
    Step: Write \(9.5\) as \(9.500\); subtract: \(9.500 - 3.485 = 6.015\).
  3. \(0.6 \times 0.07 = 0.042\).
    Step: \(6 \times 7 = 42\); decimal places: \(1 + 2 = 3\); so \(0.042\).
  4. \(0.045 \div 0.03 = 1.5\).
    Step: Multiply both by 100: \(4.5 \div 3 = 1.5\).
  5. Point should be drawn at the tick mark labeled \(0.6\) (the sixth small tick after 0 if ticks are every 0.1).
  6. The digit \(9\) is in the hundredths place.
    Step: In \(0.592\), tenths = 5, hundredths = 9, thousandths = 2.
  7. \(\$12.50 - (\$3.75 + \$1.25) = \$12.50 - \$5.00 = \$7.50\).
    Step: Add the costs first, then subtract from the total.
  8. \(2.4 \div 6 = 0.4\) meters.
    Step: \(24 \div 6 = 4\), one decimal place gives 0.4.
  9. \(0.8 \times 0.05 = 0.04\).
    Step: \(8 \times 5 = 40\); decimal places: \(1 + 2 = 3\); \(0.040 = 0.04\).
  10. \(0.72 \div 0.9 = 0.8\).
    Step: Multiply both by 10: \(7.2 \div 9 = 0.8\).
